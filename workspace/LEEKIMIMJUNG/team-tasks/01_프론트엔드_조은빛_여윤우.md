## 1. 시작하기 전에 알아야 할 것

### 기본 지식
- HTML/CSS/JS 기초 (React를 써도 되고 바닐라JS로 해도 됩니다 — 이 참가팀 서비스는 프레임워크 자유. `apps/simulator-web`처럼 이 저장소 안의 다른 앱과 형식을 맞출 필요 없음)
- 접근성 마크업 기초 — 시맨틱 태그, `aria-label`, 키보드 포커스 순서. 병원 환경 특성상 큰글씨/음성안내/청각지원/키보드전용 요구가 필수라 처음부터 신경 써야 함
- 폼 상태 관리 기초 (입력값 저장, 선택지 관리, 버튼 클릭 시 다음 단계로)

### 이 프로젝트만의 핵심 개념
- 우리가 만드는 건 딱 2개 함수의 "몸통"입니다: `collectProfile()`와 `collectUserDecision()` (`workspace/LEEKIMIMJUNG/src/participant.ts`). 함수 안에서 실제 화면을 띄우고, 사용자가 입력/클릭하면 그 결과를 반환(Promise)하는 구조라고 생각하면 됨.
- **로그인은 선택 기능** — 로그인 없이도 "이번 한 번만 이용" 경로로 전체 흐름이 항상 가능해야 함.
- **증상 질문 절대 금지** — 진료과를 물을 때 "어디가 아프세요?"가 아니라 "어느 과로 오셨어요? 모르시면 일반안내로 도와드릴게요"처럼 질문해야 함.
- **자동으로 불러온 값은 화면에 보여주고 확인받기** — 임의로 채워서 바로 넘기면 안 됨.
- **"확인" 버튼 없이 자동 진행 금지** — 특히 추천 → 실행 사이엔 반드시 사용자 승인 버튼이 있어야 함.

### 우리가 안 만들어도 되는 것
- 디지털 트윈 시뮬레이터 자체(공식 제공, `apps/simulator-web`) — 우리는 그 결과를 "연동/링크"만 하면 됨, 재구현 아님

## 2. 시작 순서

### 0단계 — 디자인팀 시안 기다리지 않고 화면 얼개부터
디자인팀(김도윤, 황소윤) 시안이 다 나올 때까지 기다릴 필요 없습니다. 어떤 항목을 받아야 하는지는 아래 표에 이미 정리돼 있으니, 와이어프레임 없이도 얼개(버튼, 인풋 배치)부터 잡고 시작 가능. 시안 나오면 스타일만 입히면 됨.

### 1단계 — 서비스 유형 선택 화면 + 접근성 설정 입력 화면 (STEP 1 앞부분)
- 방문유형(초진/재진/건강검진/검사/모름), 예약여부(있음/없음/모름) 선택 UI
- 접근성: 큰글씨/쉬운문장/시각안내/청각지원/이동지원/고대비/직원도움선호 토글

### 2단계 — 선택적 로그인 UI + 건너뛰기/비회원 경로 구현
- 로그인 버튼 + "로그인 없이 계속하기" 버튼 둘 다 명확히 보이게
- 비회원 경로로 끝까지 흐름이 막히지 않는지 직접 눌러서 확인

### 3단계 — 사용자 선택/수정 화면 구현 (STEP 1 마무리)
- 진료과 직접 선택 UI (증상 질문 없이), 보호자 동행 여부
- 입력 끝나면 `collectProfile()`이 반환할 `RawUserInput` 객체로 조립

### 4단계 — 후보 추천 결과 + 추천 이유 표시 화면 구현 (STEP 8 앞부분)
- AI팀의 `recommend()` 완성을 기다릴 필요 없이, 정해진 `Recommendation` 타입 모양으로 목데이터 만들어서 먼저 화면 작업 가능
- 추천 이유(`recommendationReasons`) 최소 1개 문장으로 표시, 대안(`alternativeCandidateIds`)도 같이 노출

### 5단계 — 최종 확인(승인) 화면 구현 (STEP 8 완성)
- 수락 / 거절 / 다른 후보 선택 / 다시 입력 — 4가지 경로 버튼 모두 존재
- 거절 시 다음 단계로 안 넘어가고 여기서 끝나는지 확인

### 6단계 — 디지털 트윈 시뮬레이터 재생 화면 연동 (선택, 여유 있으면)
- 백엔드팀의 Evidence 조회 API가 준비되면, 승인 후 결과 화면에 공식 시뮬레이터 재생 화면 링크/embed
- 필수 아님 — 시간 부족하면 생략 가능

### 7단계 — 통합 & 접근성 수동 테스트 (전원)
- [ ] 키보드만으로 전체 흐름 가능
- [ ] 화면 확대 200%에서 사용 가능
- [ ] 색상 없이(흑백으로) 상태 이해 가능
```bash
npm run participant:progress -- --team LEEKIMIMJUNG
```
