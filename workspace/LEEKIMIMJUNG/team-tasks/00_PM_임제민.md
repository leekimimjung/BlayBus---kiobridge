## Git 충돌 방지 규칙 (중요)
9개 함수가 전부 한 파일에 있음. 규칙:
1. 본인 담당 함수 **본문만** 수정 (다른 사람 함수 건드리지 않기)
2. 커밋은 함수 단위로 잘게 (`feat: collectProfile 구현` 처럼)
3. 자주 pull → 늦게 커밋하는 사람이 충돌 직접 해결
4. 타입(`UserProfile`, `SessionContext`, `Candidate` 등)은 이미 `@kiobridge/participant-sdk`가 고정해뒀으니, **서로 기다릴 필요 없이 오늘부터 병렬 작업 가능**

## 절대 원칙 (전체 팀 공통, 위반 시 검증 FAIL)
- `validationMode: "SIMULATION_ONLY"`, `executionEnvironment: "DIGITAL_TWIN"`, `actualDeviceCommandSent: false` — 항상 이 값
- 로그인 없이도 핵심 흐름(입력→추천→이유확인→승인→시뮬레이션) 가능해야 함
- 실제 개인정보(이름/전화번호/주소/주민번호/환자번호/진료정보) 절대 입력·저장 금지 — 가상 데이터만
- **증상으로 진료과 추론 절대 금지** — 진료과는 사용자가 직접 말한 것만 사용, 모르면 `UNSPECIFIED` 또는 직원 도움
